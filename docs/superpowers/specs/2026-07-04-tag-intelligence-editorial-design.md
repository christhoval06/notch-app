# Tag Intelligence Editorial Design

## Goal

Upgrade the `Tag Intelligence` section so it visually matches the premium direction already established in `Top Partners`, `Protection`, and `Day & Time`.

## Direction

Keep the recommended editorial-card approach and expand the surfaced list from `top 3` to `top 5`.

The section should feel curated, not tabular:

- each tag appears as a compact premium card
- each card emphasizes `count` and `avg rating`
- supporting metadata shows `frequent partner` and `dominant mood`
- cards should have subtle visual variation so the list does not feel flat

## Scope

Included:

- change `StatsTagSummaryService` from `top 3` to `top 5`
- redesign `StatsTagIntelligenceSection` into more premium cards
- preserve existing data points
- keep files under project size limits

Not included:

- new tag-level analytics
- tag drill-down navigation
- tag-specific charts

## Success Criteria

The update is successful when:

1. `Tag Intelligence` feels visually consistent with the upgraded premium sections.
2. The section surfaces `top 5` tags without becoming visually dense.
3. KPI hierarchy is clearer than the current plain text rows.
